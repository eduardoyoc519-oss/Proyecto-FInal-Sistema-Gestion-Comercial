# SISTEMA DE GESTION COMERCIAL

## DESCRIPCION
sistema de gestion comercial desarrollado en Python para administrar productos, controlar inventarios, registrar ventas con cálculo de IVA (12%), consultar historiales y generar reportes estadísticos mediante archivos JSON

## ESTRUCTURA DEL PROYECTO
- `src/`: Contiene el código fuente modular del sistema (`main.py`, `productos.py`, `ventas.py`, `inventario.py`, `reportes.py`, `archivos.py`)
- `data/`: Almacena los archivos JSON de persistencia de datos
- `docs/`: Contiene el análisis de procesos, diagramas, manual técnico y manual de usuario
- `evidencias/`: Capturas de pantalla de las pruebas del sistema

## REGISTRO DE EJECUCION
- Python 3.x instalado en el equipo.
- No requiere librerías externas adicionales.

## INSTRUCCIONES 
1. Abra una terminal en la carpeta raíz del proyecto O su compilador vs .
2. Ingrese a la carpeta de código fuente: `cd src`
3. Ejecute el programa principal: `python main.py`
