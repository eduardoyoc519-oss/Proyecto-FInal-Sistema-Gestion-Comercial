# MANUAL DE USUARIO - SISTEMA DE GESTION  COMERCIAL

## 1. Bienvenida
Este manual le guiarA en el uso del sistema comercial para realizar operaciones diarias sin necesidad de conocimientos avanzados en programación

## 2. Inicio del Sistema
1. Abra la terminal de comandos de su sistema operativo o compilador vs.
2. Navegue hasta la carpeta `src/` del proyecto.
3. Ejecute el comando: `python main.py`

## 3. Uso del Menú Principal
Al iniciar, verá un menú numerado del 1 al 5:
- **1. Módulo de Gestión de Productos**: Permite registrar nuevos artículos, consultarlos por código, listar todo el inventario, modificarlos o desactivarlos.
- **2. Módulo de Registro de Ventas**: Le permite ingresar productos mediante códigos, verificar existencias, calcular totales con el 12% de IVA incluido y generar comprobantes automáticos.
- **3. Módulo de Control de Inventarios**: Ideal para revisar existencias actuales y registrar entradas de mercadería nueva.
- **4. Módulo de Reportes y Estadísticas**: Muestra listados de stock mínimo, ingresos totales, productos más vendidos y valor total del inventario.
- **5. Salir**: Cierra el sistema de forma controlada.
